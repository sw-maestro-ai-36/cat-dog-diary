# Prompt Iterations

일기 생성 시스템 프롬프트 변경 이력. 새 버전이 나올 때마다 위에 추가 (역순).

## 포맷

```
## v{N} → v{N+1} ({YYYY-MM-DD})
변경: [무엇을 바꿨는지 1-2줄]
이유: [어떤 문제를 해결하려고 / 어떤 가설을 검증하려고]
평가: [평가 셋 결과 — N건 중 M건 통과, 부작용]
액션: [후속 조치 — 룰 추가, 재튜닝 예정 등]
```
