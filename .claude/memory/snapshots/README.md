# Phase Snapshots

각 Phase 종료 시점에 "지금 무엇이 됐는지"를 동결한다. 새 세션 진입 시 가장 최근 스냅샷만 읽으면 컨텍스트 복원 가능하도록.

## 파일명 규칙

`phase-{N}-{slug}.md` (예: `phase-0-foundation.md`)

## 템플릿

```markdown
# Phase {N}: {제목} (완료: YYYY-MM-DD)

## 완료된 것
- [ ] (Phase 종료 기준 체크리스트 결과)

## 결정된 것 (ADR으로 격상 안 한 사소한 결정)
-

## 다음 Phase로 넘기는 것
- 미해결 이슈
- 검토 보류된 옵션

## 코드 상태
- 주요 추가/변경 파일 목록 (10개 내외)
```
