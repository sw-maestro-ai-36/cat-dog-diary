# Skills

반복되는 워크플로우 정의. Claude Code skill 규약을 따른다 (각 스킬은 자체 디렉토리 + `SKILL.md`).

## 후보 (필요해지면 추가)

- `add-langgraph-node/` — 새 LangGraph 노드 추가 절차 (state 확장 → 노드 구현 → 그래프 연결 → 테스트)
- `add-pet-attribute/` — 반려동물 프로필 속성 추가 (마이그레이션 → 타입 → UI → 프롬프트 반영)
- `add-adr/` — 새 ADR 생성 (다음 번호 부여, 템플릿 채우기)

## 추가 기준

- 동일 절차를 3회 이상 반복했을 때
- 절차가 길어서 한 번에 다 기억하기 어려울 때
- 빠뜨리면 안 되는 단계가 있을 때 (예: RLS 빼먹기)
