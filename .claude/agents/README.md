# Subagents

도메인 특화 작업을 전담시킬 서브에이전트 정의 위치. Claude Code의 agent 시스템 규약을 따른다.

## 후보 (필요해지면 추가)

- `prompt-tuner.md` — 일기 시스템 프롬프트 변경 시 평가 셋 자동 실행 + 비교 리포트
- `migration-writer.md` — Supabase SQL 마이그레이션 생성 (RLS 자동 포함)
- `cost-auditor.md` — LangSmith 트레이스 분석해 비용/지연 이상 탐지

## 추가 기준

- 같은 종류 작업이 5회 이상 반복되었을 때
- 작업이 컨텍스트를 많이 잡아먹어서 메인 세션 토큰을 압박할 때
- 일관성이 중요한 작업 (프롬프트, 마이그레이션 같은)

너무 일찍 만들면 사용 안 하고 묵힘.
